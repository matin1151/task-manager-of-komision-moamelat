دستیار کمیسیون معاملات — نسخه محلی

فایل اصلی: index.html

راه‌اندازی پیشنهادی در ویندوز:
1) Python 3 را روی سیستم داشته باشید.
2) روی start.bat دوبار کلیک کنید.
3) مرورگر روی http://127.0.0.1:8765/index.html باز می‌شود.

آلارم:
- از بخش «تنظیمات» روی «فعال‌سازی آلارم‌ها» بزنید.
- آلارم‌های تاریخ‌های ثبت‌شده با بررسی هر ۳۰ ثانیه اجرا می‌شوند.
- در این نسخه، برای اجرای مطمئن آلارم باید صفحه/مرورگر باز باشد.
- اعلان پس‌زمینه هنگام بسته بودن صفحه نیازمند نسخه PWA/سرویس پس‌زمینه و زیرساخت اعلان است.

داده‌ها:
- اطلاعات فعلی در localStorage همان مرورگر ذخیره می‌شود.
- از «خروجی پشتیبان JSON» برای پشتیبان‌گیری استفاده کنید.

این نسخه هنوز نسخه سروری چندکاربره یا اتصال به SETAD نیست.
