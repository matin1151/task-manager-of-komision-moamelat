Dastyar Komision - Windows Delivery
==================================

نصب برای کاربر نهایی
-------------------

1. پوشه DastyarKomision-Windows را از حالت zip خارج کنید.
2. روی install.bat دوبار کلیک کنید.
3. بعد از نصب، برنامه با میانبر Desktop با نام Dastyar Komision اجرا می‌شود.

کاربر نهایی به Git، Python یا اجرای دستی PowerShell نیاز ندارد. Python قابل‌حمل داخل پوشه runtime همراه بسته است.

مسیرهای نصب
-----------

- فایل‌های برنامه:
  %LOCALAPPDATA%\Programs\DastyarKomision

- داده‌های کاربر و دیتابیس:
  %LOCALAPPDATA%\DastyarKomisionData

داده‌ها جدا از برنامه نگهداری می‌شوند؛ بنابراین نصب دوباره یا حذف برنامه، اطلاعات معاملات را پاک نمی‌کند.

اجرای پس‌زمینه
--------------

نصب‌کننده یک میانبر Startup می‌سازد. بعد از ورود کاربر به ویندوز، launcher فقط سرور محلی را در پس‌زمینه بررسی و روشن می‌کند و مرورگر را باز نمی‌کند. میانبر دسکتاپ مرورگر را باز می‌کند. اگر پورت ۸۷۶۵ اشغال باشد، برنامه از یکی از پورت‌های محلی جایگزین استفاده می‌کند.

امنیت و پشتیبان
---------------

ذخیره‌سازی با توکن محلی، بررسی Host/Origin، نسخه‌گذاری و قفل تراکنش انجام می‌شود. هنگام هر ذخیره، نسخه قبلی دیتابیس در پوشه backups نگه‌داری می‌شود و چند نسخه اخیر حفظ می‌شوند. اگر دو تب هم‌زمان ذخیره کنند، نسخه قدیمی بازنویسی نمی‌شود.

فونت فارسی داخل بسته قرار دارد و برنامه برای اجرا به اینترنت نیاز ندارد.

حذف برنامه
----------

از Start Menu مسیر Dastyar Komision > Uninstall را اجرا کنید، یا فایل uninstall.ps1 داخل مسیر نصب را اجرا کنید. حذف برنامه میانبرها و فایل‌های برنامه را برمی‌دارد، اما پوشه داده را نگه می‌دارد.

برای حذف کامل اطلاعات، فقط در صورتی که مطمئن هستید، پوشه زیر را دستی حذف کنید:

%LOCALAPPDATA%\DastyarKomisionData

تست سلامت
---------

از Start Menu مسیر Dastyar Komision > Health Check را اجرا کنید. اگر برنامه سالم باشد، مسیر دیتابیس و پوشه داده نمایش داده می‌شود.
