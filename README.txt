دستیار کمیسیون معاملات — نسخه محلی

فایل اصلی: index.html

راه‌اندازی در ویندوز:
1) Python 3 را روی سیستم داشته باشید.
2) روی start.bat دوبار کلیک کنید.
3) فایل start.bat منتظر آماده‌شدن واقعی سرور محلی می‌ماند و سپس برنامه را در مرورگر باز می‌کند.
4) پنجره سرور را تا زمانی که به آلارم‌های پس‌زمینه نیاز دارید نبندید.

آلارم:
- موعدها هر ۳۰ ثانیه بررسی می‌شوند.
- وقتی مرورگر باز است، با فعال‌کردن اعلان‌ها از بخش «تنظیمات» اعلان مرورگر نیز دریافت می‌کنید.
- سرور پس‌زمینه موعدهای اصلی معامله شامل انتشار/شروع، دریافت اسناد، ارسال پیشنهاد، بازگشایی، اعلام برنده و موعد کارهای سفارشی را بررسی می‌کند.
- زمان‌های شمسی برنامه بر مبنای ساعت تهران تفسیر می‌شوند.
- سابقه آلارم‌های اجراشده در دیتابیس ذخیره می‌شود تا با راه‌اندازی مجدد سرور بی‌دلیل تکرار نشوند.

داده‌ها:
- منبع اصلی اطلاعات فایل محلی `komision.db` کنار برنامه است و با بستن مرورگر باقی می‌ماند.
- localStorage مرورگر فقط برای سازگاری و مهاجرت نسخه‌های قبلی نگه داشته شده است.
- از «خروجی پشتیبان JSON» برای تهیه نسخه پشتیبان استفاده کنید.

این نسخه محلی و تک‌کاربره است و اتصال مستقیم به سامانه SETAD ندارد.
